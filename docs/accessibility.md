# 접근성 품질 계약

- 모든 핵심 조작을 키보드로 완료할 수 있어야 합니다.
- 모달과 서랍 패널은 최초 초점, Tab 순환, Escape 닫기, 이전 초점 복귀를 제공합니다.
- 모바일 컴포넌트 탐색기는 모달 대화 상자로 노출하며, 열린 동안 주 작업 영역과 보조 패널을 `inert`와 `aria-hidden`으로 비활성화합니다.
- 선택 상태는 색상 외에도 `aria-selected`, `aria-pressed`, `aria-current`로 전달합니다.
- 현재 화면에 없는 플랫폼 탭은 DOM에서 제거해 잘못된 `aria-controls` 관계를 만들지 않습니다.
- 컴포넌트 상태 샘플은 `inert`와 `aria-hidden`으로 중복 조작 요소를 노출하지 않습니다.
- 카드 이미지는 대체 텍스트, 고정된 고유 크기, 반응형 이미지 소스를 제공합니다.
- 애니메이션은 `prefers-reduced-motion`에서 제거합니다.

Vitest axe는 초기 화면, Figma 변경 검토 서랍, 릴리스 리허설 대화 상자에서 WCAG 2.0 A/AA, 2.1 A/AA, 2.2 AA 태그에 해당하는 모든 위반을 심각도와 관계없이 차단합니다. JSDOM은 실제로 화면을 그리지 않으므로 이 단계에서 색상 대비 규칙만 비활성화합니다.

Playwright는 실제 Chromium에서 여섯 컴포넌트의 선택 상태마다 같은 WCAG 태그 전체와 색상 대비를 다시 검사합니다. 같은 검증 스위트에서 순환 탭 탐색, 스크롤 영역의 키보드 접근, 1280px 경계를 확인합니다.

200% 확대에 해당하는 뷰포트와 모바일 서랍 패널, 강제 색상 모드의 초점 표시, 컴포넌트별 시각 기준 이미지도 검사합니다.

위반이 발생하면 전체 목록을 실패 근거로 보존하며 심각도 등급을 필터링하지 않습니다.

자동화는 실제 스크린리더 발화를 완전히 대신하지 않습니다. 배포 전 VoiceOver와 NVDA 또는 동등한 보조 기술에서 읽기 순서와 안내 문구를 직접 확인해야 하며, 이 저장소는 해당 수동 검증을 완료했다고 주장하지 않습니다.
