# AI 산출물 운영 원칙

AI는 문서 초안, 테스트 후보, 마이그레이션 codemod 제안에만 사용합니다. 다음 항목은 자동 승인하지 않습니다.

- 공개 컴포넌트 API 변경
- semantic token 의미 변경
- 접근성 예외와 contrast 기준 완화
- semver 분류와 deprecation 종료
- 패키지 배포 또는 소비 앱 자동 병합

모든 AI 산출물은 입력 근거, 생성 시점, 모델 또는 도구 식별자, 변경 diff, 실행된 검증과 최종 검토자를 남겨야 합니다. 결정적인 타입·단위·axe·시각 회귀 검증이 실패하면 사람의 승인 여부와 관계없이 릴리스를 차단합니다.
