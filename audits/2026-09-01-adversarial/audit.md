## 재검증 항목

1. DTCG와 CSS, Swift, Compose 크기 값 및 단위 일치
2. 생성 매니페스트와 Studio API 구조 일치
3. 복사 가능한 소비 예제 타입 검사
4. 소스 리비전, 커밋, 실행 ID, 시각, 해시가 있는 근거와 테스트 후 검증 근거를 빌드하는 순서
5. import를 해석하는 AST 도입률 분석
6. 검토와 리허설 기록의 새로고침, 손상, 구버전 스키마, 멱등성 검증
7. 모든 WCAG 태그 기반 axe 결과와 키보드 및 강제 색상 모드 검증
8. 플랫폼 탭의 지원 범위와 실제 산출물 표현 일치
9. 패키지 내용, 네이티브 수치 계약, Swift 컴파일 스모크 테스트
10. 이미지 해시, Action SHA, 서비스 계정, 앱 상태 검사
11. 1440px, 1280px, 확대에 해당하는 뷰포트, 모바일 반응형 시각 계약
12. 현재 빌드 리비전과 품질 근거가 다를 때 릴리스 차단
13. 오래되거나 변조된 출처 정보 거부
14. 페이지 오류, 콘솔 오류, HTTP 4xx 및 5xx 응답이 없는 프로덕션 브라우저 흐름
